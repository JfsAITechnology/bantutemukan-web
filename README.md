# Bantutemukan.id

Tulis kebutuhanmu, kami carikan UMKM Surabaya yang cocok. Desain awal (prototipe) halaman web Bantutemukan.id, tema biru tua, mode terang dan gelap.

## Isi

| File | Fungsi |
|---|---|
| `index.html` | Halaman utama untuk pembeli |
| `umkm.html` | Halaman untuk pemilik UMKM (ajakan mendaftar) |
| `dashboard-pembeli.html` | Desain dashboard pembeli (data contoh) |
| `dashboard-umkm.html` | Desain dashboard UMKM (data contoh) |

Semua file berdiri sendiri (tanpa instalasi). Buka `index.html` di browser untuk melihatnya.

## Yang masih harus diganti sebelum rilis

- [ ] Nomor WhatsApp: cari `62XXXXXXXXXX` di `index.html` dan `umkm.html`
- [ ] Biaya untuk UMKM: cari `[Gratis untuk UMKM` di `umkm.html`
- [ ] Data contoh ("UMKM Contoh A/B", harga, jumlah) diganti data UMKM asli
- [ ] Dashboard masih berupa desain; belum terhubung ke database atau Asisten AI
